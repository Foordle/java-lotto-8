## a. 주제설명 및 간단한 도식
이번 미션의 과제는 ***로또 발매기***의 구현이다.<br>
로또 구입 금액과(개당 1000원) 당첨번호와 보너스 번호를 입력 받고 로또의 당첨 수량 및 번호를 출력해야한다.
---
## b. 기능 목록
정상적인 경우와 예외경우에 대해 구분하여 작성하였다.

### 1. 로또 구입 및 발행
| 기능 | 설명 |
|---|---|
| **구입 금액 입력** | 사용자로부터 로또 구입 금액을 입력받는다. |
| **로또 발행** | 구입 금액(1,000원 당 1장)에 맞춰 로또를 발행하고 발행 수량을 출력한다. |
| **로또 번호 출력** | 발행된 각 로또의 번호 6개를 오름차순으로 정렬하여 출력한다. |

### 2. 당첨 번호 및 보너스 번호 입력
| 기능 | 설명 |
|---|---|
| **당첨 번호 입력** | 쉼표(`,`)를 기준으로 구분된 당첨 번호 6개를 입력받는다. |
| **보너스 번호 입력** | 당첨 번호와 구분되는 보너스 번호 1개를 입력받는다. |

### 3. 당첨 확인 및 결과 출력
| 기능 | 설명 |
|---|---|
| **당첨 내역 계산** | 구매한 로또와 당첨 번호를 비교하여 등수별 당첨 횟수를 계산한다. |
| **당첨 통계 출력** | 3개 일치(5등)부터 6개 일치(1등)까지 당첨 통계를 정해진 형식으로 출력한다. |
| **수익률 계산 및 출력** | 총 수익률을 계산하고 소수점 둘째 자리에서 반올림하여 출력한다. |

### 4. 예외 처리
사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력 후 해당 부분부터 입력을 다시 받는다.

| 구분 | 예외 상황 |
|---|---|
| **구입 금액** | 구입 금액이 1,000원 단위가 아닌 경우. |
| | 구입 금액에 숫자가 아닌 문자가 포함된 경우. |
| **로또 번호 (발행 및 당첨)** | 로또 번호의 개수가 6개가 아닌 경우. |
| | 로또 번호에 중복된 숫자가 존재하는 경우. |
| | 로또 번호가 1~45 범위를 벗어난 경우. |
| **보너스 번호** | 보너스 번호가 1~45 범위를 벗어난 경우. |
| | 보너스 번호가 이미 당첨 번호 6개에 포함된 경우. |

### 기능 요구 사항
간단한 로또 발매기를 구현한다.
- [x] 로또 번호의 숫자 범위는 1~45까지이다.
- [x] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- [x] 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- [x] 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- [x] 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- [x] 로또 1장의 가격은 1,000원이다.
- [x] 당첨 번호와 보너스 번호를 입력받는다.
- [x] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
  사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
   - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
